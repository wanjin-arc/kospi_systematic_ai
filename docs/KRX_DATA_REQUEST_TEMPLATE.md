# KRX 과거 데이터 요청 문안

아래 내용을 KRX Data Marketplace의 Historical Data / Custom Data Inquiry에서 그대로 사용하거나, 데이터 제공 담당자에게 전달할 수 있다.

---

## 요청 목적

개인 자산 운용을 위한 KOSPI 100 일봉 기반 시스템 트레이딩 연구 및 향후 내부 비조회형 자동매매 검증에 사용하고자 합니다. 제3자 재배포 목적은 없습니다.

## 요청 기간 및 지수

- 기간: 2011-01-01 ~ 2025-12-31
- 대상 지수: KOSPI 100
- 데이터 기준: 각 과거 시점에 실제로 유효했던 구성종목
- 현재 구성종목을 과거에 소급한 자료는 사용할 수 없음

## 요청 데이터

1. **KOSPI 100 과거 구성종목**
   - 종목코드, ISIN, 종목명
   - 편입 효력일, 편출 효력일
   - 변경 발표일시 또는 공지일
   - 정기변경과 수시변경 구분
   - 매 거래일 구성종목을 정확히 복원할 수 있는 스냅숏 또는 전체 변경 이력

2. **구성종목 일별 원시 시세**
   - 거래일, 종목코드, 시가, 고가, 저가, 종가
   - 거래량, 거래대금
   - 수정 전 원시가격 여부 표시
   - 거래정지일 및 가격 미생성 상태 구분
   - 편출·상장폐지 종목 포함

3. **KOSPI 100 지수 일별 시세**
   - 거래일, 지수코드, 시가, 고가, 저가, 종가
   - 거래량과 거래대금이 제공되는 경우 함께 포함

4. **Corporate Action 및 종목 식별 이력**
   - 액면분할, 병합, 무상증자·주식배당 등 주식 수 조정 사건
   - 발표일시, 기준일/효력일, 조정비율
   - 종목코드 변경, 합병, 분할, 상장일, 상장폐지일

5. **거래 가능 상태**
   - 거래정지 시작일과 종료일
   - 정리매매 및 상장폐지 상태
   - 해당 기간의 가격제한 또는 미체결 판단에 필요한 상태 필드가 있으면 포함

6. **KRX 거래일 달력**
   - 거래일 여부
   - 개장·폐장 시각
   - 조기 종료 또는 임시 휴장 여부

## 제공 형식

- UTF-8 CSV 또는 Parquet
- 날짜: `YYYY-MM-DD`
- 일시: KST 및 시간대 정보 포함
- 각 파일의 데이터 사전과 조정가격 정의 포함
- 자료명, 추출일시, 버전, 조회 조건 또는 상품 코드 포함
- 가능하면 파일별 SHA-256 또는 원본 무결성을 확인할 수 있는 정보 포함

## 라이선스 확인 요청

다음 용도의 허용 범위와 별도 계약·신고 필요 여부도 안내해 주시기 바랍니다.

- 개인의 내부 과거 데이터 연구
- 데이터의 로컬 저장과 기술적 변수 계산
- 모의투자
- 본인 계좌의 비조회형·알고리즘 주문 생성
- 제3자에게 원시 데이터를 재배포하지 않는 경우
