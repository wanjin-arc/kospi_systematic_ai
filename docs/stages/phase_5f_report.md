# Phase 5F 시계열 경로·시장 이상상태 모델 실행 보고서

## 1. 결론

`EXP-20260823-006`을 2019~2021 adaptive diagnostic 구간에서 실행했다. 8개 종목 기술변수의 최근 5·20거래일 경로와 5개 시장변수 경로를 얕은 HistGradientBoosting 평균·중앙값 회귀에 입력하고, 각 fold Train에서만 적합한 IsolationForest 이상상태에서는 신규매수를 보류했다.

전략 수익률은 -7.8257%, KOSPI 100은 +50.3994%, 순초과수익률은 -58.2251%p였다. 기본비용·2배 비용 순초과수익 gate와 연도 안정성을 실패했다. 거래 후보와 Development Test 후보는 없다. 2019~2021은 이미 소비된 구간이므로 결과는 Test/OOS가 아니다.

## 2. 논문 아이디어를 적용한 방식

7편의 논문에서 기술지표 결합, 시계열 경로 표현, 종목·시장 입력 분리, 비지도 이상탐지, 상태·행동·비용 차감 보상의 분리라는 구조적 아이디어만 차용했다.

외부 거시지표·환율·금리·뉴스·기업 텍스트는 저장소 Factor 범위 밖이므로 사용하지 않았다. 논문의 가격 수준 RMSE·R², 현재 대형주를 고른 표본, 전체 기간을 보고 조정한 이상치 임계값도 성과 증거로 사용하지 않았다. LSTM·Transformer·Mamba·강화학습은 복잡도 대비 독립 검증 증거가 부족해 구현하지 않았다.

## 3. 변수와 관계

종목 기본변수는 `reversal_5`, 20·63일 시장초과 모멘텀, 20·60·200일 추세, 20일 저변동성, 5일 대 20일 거래량 확인이다. 각 변수에 다음 변환을 적용했다.

- 당일 횡단면 rank: 현재 상대 위치
- 5일 rank 변화: 최근 가속·감속
- 20일 평균: 일시적 신호와 지속 상태의 구분
- 20일 표준편차: 순위 안정성
- 20일 중 상위 절반 비율: 방향 지속성

시장변수는 KOSPI 100 장기 추세·중기 모멘텀·단기 변동성과 Universe Breadth 2개이며, 당일 값·5일 변화·20일 변동을 사용했다. 평균 회귀는 예상 비용 차감 초과수익을, 중앙값 회귀는 이상치에 덜 민감한 전형적 결과를 추정했다. 두 값이 각각 0.3% 이상·0 초과이고 시장이 비이상 상태일 때만 평균 예상 초과수익 순으로 매수했다.

최종 채택 변수는 없다. 이 Feature·모델 묶음은 시간 안정성과 경제성 gate를 통과하지 못했다.
