# v2 Phase 3E Agent C4 실행 보고서

## 결론

`EXP-20260826-010`은 구현·실행·독립 재현을 완료했지만, Agent C3를 대체할 만큼 강한 예측력을 만들지 못했다. C4는 거래 후보가 아니며 D4 진단 입력으로만 사용했다.

## 구현과 실행

- 실제 PyTorch LSTM과 1D CNN의 표현을 결합했다.
- 회귀 head는 t+1 시가부터 t+11 시가까지의 비용 차감 종목 수익률에서 같은 기간 공식 KRX KOSPI200 수익률을 뺀 값을 예측한다.
- 분류 head는 위 초과수익이 양수인지 예측한다.
- 2004~2018로 적합했고 2017~2018 calibration 앞에 거래소 세션 기준 purge 10·embargo 10을 적용했다.
- 2019~2023은 이미 소비된 개발 진단으로만 평가했다.

## 결과

- 평균 일별 초과수익 Rank IC: `0.011919`
- 양수 초과수익 AUC: `0.503193`
- 초과수익 MAE: `0.050495`
- 연도별 IC 양수: `3/5`
- 2019 `0.002981`, 2020 `-0.021649`, 2021 `0.059931`, 2022 `0.028546`, 2023 `-0.011469`

Train 내부 calibration도 Rank IC `0.001673`, AUC `0.492142`로 약했다. 따라서 소비된 개발기간에서 보인 일부 양의 IC만으로 구조를 승격하지 않는다.

## 재현성과 경계

본 실행과 독립 재실행의 6개 파일이 모두 byte-identical이었다. Final OOS, v1 Development Test, Agent B, 포트폴리오에는 접근하지 않았다.
