## 결론

`EXP-20260826-012`는 거래 후보로 **기각**한다. 관계 모델의 분류 성능은 2021~2023
소비 개발구간에서 AUC 0.6214였지만, 사전등록한 최소 성공확률 0.50을 만족한 행이 한 건도
없어 주문과 체결이 모두 0건이었다. 전략 수익률 0%와 지수 수익률 -12.79%의 차이
+12.79%p는 종목선택 알파가 아니라 현금 100% 보유 결과다.

## 실제 사용 데이터

- Agent B2: 확정·정규화된 2016~2023 펀더멘털 품질 점수
- Agent C3: 실제 PyTorch LSTM 변동성 점수와 1D CNN 2:1 barrier 성공확률
- 관계 적합: 2019-01-02~2019-12-02
- 결합비·임계값 선택: 2020-01-20~2020-12-30
- 최종 재적합: 2019-01-02~2020-12-01
- 최종 소비 개발 진단: 2021-01-18~2023-12-28

2011~2014 구형 DART 원문은 ZIP/XML 구조 분류만 완료됐고 표준 수치계정, 역사적
ticker–법인 identity 및 PIT 유효일 감사가 완료되지 않았다. 따라서 이번 모델에 사용한
행은 0개다. 이를 “2016년 이전 재무제표를 학습했다”고 해석해서는 안 된다.

## 모델과 변수 관계

얕은 `HistGradientBoostingClassifier`가 다음 값을 함께 사용해 +10%가 -5%보다 먼저
발생할 확률을 추정했다.

- B2 펀더멘털 품질 percentile
- C3 기술점수 percentile
- CNN 성공확률과 LSTM 예측 변동성 percentile
- B×C, B×CNN, C×CNN 상호작용
- B/C 순위 일치도
- 변동성으로 감쇠한 C 점수

2020년에만 B 비중 0·25·50·75%, 확률 임계값 0.50·0.55·0.60, 일별 점수 상위
10%·5%를 조합한 24개 정책을 비교했다. 선택 정책은 `B000_P050_Q090`이었지만,
24개 정책 모두 주문 0건이라 실질적으로 우열을 결정하지 못했다.

## 해석과 후속 제한

이번 결과는 “변수 관계를 고려하는 모델이 불가능하다”는 증명은 아니다. 다만 양성 사건의

수정하거나 또 다른 모델을 만들지 않는다. 다음 유효 성과 검증은 동결한 정책을
