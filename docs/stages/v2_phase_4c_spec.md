# v2 Phase 4C — Agent D3 LSTM·CNN 매매 명세

## 상태

- Experiment ID: `EXP-20260826-009`
- 상태: 결과 확인 전 사전등록 완료
- 입력: hash 동결된 C3 실제 LSTM·CNN 점수와 B2 품질점수

## 후보

1. `C3_ONLY`: C3 최종점수만으로 일별 우선순위를 결정한다.
2. `C3_B2_RISK_CALIBRATION`: C3 종목을 제거하지 않고 B2 percentile로 우선순위만 보정한다.

## 사용자 제시 매매 규칙

- C3 최종점수 0.05 이상: 목표비중 5%
- C3 최종점수 0.075 이상: 목표비중 11%
- 일별 최대 후보 10개, 최대 보유 10개, 피라미딩 금지
- t일 완성 일봉 신호를 t+1 시가에 주문
- 전일 종가 대비 시가 gap 절대값 5% 초과 시 주문 취소
- 손절 -5%, 익절 +10%, 최대 10세션
- 같은 일봉에서 손절·익절이 모두 닿으면 STOP_FIRST
- 공식 KRX KOSPI200 지수 코드 1028 대비 비용 차감 성과 평가

## 결정

연결 순초과수익률, 연도별 양의 초과수익 3/5, Sharpe 양수, MDD -30% 초과, reconciliation PASS를 모두 요구한다. 2019~2023은 소비된 개발기간이므로 통과해도 독립 OOS나 실거래 후보로 자동 승격하지 않는다.

## 금지

- C3 결과를 본 뒤 0.05/0.075 임계값 변경
- LSTM/CNN 재학습 또는 B2 Top N 변경
- v1 Development Test 또는 Final OOS 접근
- 실주문·배포
