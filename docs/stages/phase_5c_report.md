# Phase 5C 점수 지속성·저회전율 Ranking 실행 보고서

## 1. 결론

`EXP-20260823-003`을 2015~2018의 이미 소비된 내부 Validation에서 실행했다. Phase 5B의 `elastic_a005_l02` 신호를 고정하고 5세션 causal EMA, 상위 10 목표·20위 fallback, 20위 이탈 청산, 20세션 안전 상한을 적용했다.

전략 수익률은 -4.1165%에서 +6.3574%로, KOSPI 100 대비 순초과수익률은 -11.5013%p에서 -1.0274%p로 개선됐다. 그러나 지수를 이기지 못했고 적응적 진단 gate 5개 중 2개를 실패했다. 따라서 Phase 5C 정책은 기각하며 거래 후보와 Development Test 후보는 없다.

## 2. Gate에 대한 판단

좋은 모델도 특정 연도의 급등장, 급락장 또는 모델 입력에 없는 외부 충격 때문에 지수를 이기지 못할 수 있다. 모든 연도의 초과수익률을 양수로 요구하면 거짓 양성을 줄이는 대신 유효한 모델까지 버리는 거짓 음성이 커진다. 특히 4개 fold에서 80% 조건은 정수상 4/4가 되어 매우 거칠다.

반대로 실패 결과를 본 뒤 연도 gate를 낮춰 같은 데이터에서 통과시키는 것은 과최적화다. 이번 실험에서는 기존 D20을 변경하지 않았다. 향후에는 연결 구간의 비용 차감 초과수익과 비용 stress를 hard gate로 두고, 연도별 양수 비율은 regime 진단으로 보고하는 방식을 권고한다. 이 변경은 `DEC-2026-047`의 제안이며 사용자 별도 승인 전 확정되지 않는다.

## 5. 사용 변수와 관계

기초 모델은 Phase 4B의 21개 종목 기술변수, 5개 동시점 시장상태, 6개 상호작용을 사용한다. ElasticNet이 대부분의 계수를 0으로 축소했고 실제 점수에 주로 남은 관계는 다음과 같다.

- `trend_close_sma200 × breadth_above_sma200`: 시장 전체에서 200일선 위 종목이 많을수록 장기 추세가 강한 종목의 점수를 높인다.
- `reversal_5`: 최근 5거래일 많이 하락한 종목에 단기 반전 가능성을 부여한다.
- `liquidity_20`: 다른 유동성 변수와 함께 극단적으로 거래대금이 큰 종목의 단순 우대를 억제한다.
- 5세션 causal EMA: 오늘 점수에 오늘과 과거 점수만 반영해 하루짜리 순위 잡음을 줄인다.
- 상위 10/20 hysteresis: 신규 진입은 상위권을 우선하되 기존 후보가 20위 밖으로 밀리기 전에는 잦은 교체를 줄인다.

즉, 매일 모든 적격 종목을 같은 내부 변수로 점수화·순위화한다는 거시적 구조는 유지했다. Phase 5C의 개선은 새로운 미래 예측 변수를 발견한 것이 아니라 약한 점수를 거래로 변환하는 과정의 마찰을 줄인 결과다.

## 6. 분봉과 데이터 독립성

분봉은 사용하지 않았다. 현재 일봉 Ranker의 장기 표본과 분봉의 최근 가용기간이 다르므로 지금 결합하면 표본이 줄고 결측 선택편향이 생긴다. 일봉 전략이 독립 확인을 통과한 뒤 동일 coverage 표본의 다음 날 시가 baseline과 5분·15분 Entry Timing을 별도 비교해야 한다.

Phase 이름을 5C로 바꿔도 이미 본 연도가 다시 미사용 데이터가 되지 않는다. 이번 실행은 2018년 이하 물리 파티션만 사용했다. 2019~2021과 2022~2023을 열지 않았고 Final OOS에도 접근하지 않았다.
