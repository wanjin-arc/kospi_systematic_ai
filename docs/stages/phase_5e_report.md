# Phase 5E 절대 알파·No-Trade 모델 실행 보고서

## 1. 결론

`EXP-20260823-005`를 2019~2021 adaptive diagnostic 구간에서 실행했다. 횡단면 상대 순위 target 대신 `t+1` 시가부터 `t+11` 시가까지의 비용 차감 절대 초과수익과 양수 여부를 각각 Ridge·Logistic으로 예측했다. 예상 순초과수익 `>=0.5%`와 양수 확률 `>=60%`를 모두 통과한 종목만 매수했다.

전략 수익률은 +29.3130%, KOSPI 100은 +50.3994%, 순초과수익률은 -21.0864%p였다. 절대 수익과 MDD는 이전 연구보다 개선됐지만 기본비용·2배 비용 순초과수익 gate를 실패했다. 거래 후보와 Development Test 후보는 없다.

2019~2021은 이미 소비된 구간이므로 이 결과는 Test/OOS가 아니다. 성과가 좋았더라도 자동 승격할 수 없는 진단이었다.

## 2. 모델과 변수 관계

고정 입력은 Phase 4B의 21개 종목 기술변수 rank, 5개 시장상태 변수, 6개 상호작용이다.

- 종목 변수: 5~252세션 반전·모멘텀·초과모멘텀, 20·60·200일 추세, 고점 근접도, 변동성·하방변동성·ATR, 위험조정 모멘텀, 거래량·거래대금 확인, 유동성·비유동성
- 시장 변수: KOSPI 100 200일 추세·63일 모멘텀·20일 변동성, Universe의 200일선 상회 비율·20일 양의 모멘텀 비율
- 상호작용: 대표 종목 신호가 시장 추세·Breadth 조건에서 달라지는 관계 6개

Ridge는 이 입력으로 예상 비용 차감 초과수익을 계산하고 Logistic은 그 초과수익이 양수일 확률을 계산한다. 시장 변수는 보유 종목 수를 강제로 정하지 않고 두 예측에만 영향을 줬다. 최종 채택 변수는 없다. 전체 고정 Feature 집합을 사용한 모델 자체가 예측 안정성과 지수 초과 gate를 통과하지 못했기 때문이다.

## 5. 예측 품질과 원인 판단

| 연도 | Ridge Spearman | Logistic AUC | 이중 gate 표본 | 실제 평균 순초과수익 | 실제 양수 비율 |

| 2020 | -0.0232 | 0.5020 | 97 | +5.3508% | 62.89% |
| 2021 | -0.0849 | 0.4518 | 0 | — | — |

실패의 중심은 no-trade 기능 자체가 아니라 절대 초과수익 예측의 불안정성이다.

1. Ridge 순위 상관은 세 연도 모두 음수였다.
2. Logistic AUC는 2019·2020에 약 0.50, 2021에는 0.45로 분류력이 안정적이지 않았다.
3. 2020년 선택 표본은 양호했지만 2019년에는 같은 gate가 음의 평균 순초과수익을 냈다.
4. 2021년에는 조건을 통과한 표본이 없어 손실은 피했지만 지수 초과 증거도 만들지 못했다.
5. 임계값을 결과에 맞춰 낮추거나 높이지 않았다.

따라서 “매수할 가치가 없으면 현금”이라는 구조는 의도대로 작동했지만, 현재 기술변수와 선형 절대 알파 모델은 어느 종목이 비용 후 지수를 이길지 안정적으로 식별하지 못했다.
