# v2 Phase 3C 공식지수 초과수익 Agent C2 실행 보고서

## 결론

`EXP-20260826-006`에서는 기존 구조를 확장한 `hist_event_dual_v1`이 선택됐다. 2004년부터의 가격 이력과 공식 KOSPI 200 지수 기준으로 평균 10세션 비용 차감 초과수익 Rank IC가 `0.04184`였고 2019~2023 다섯 연도에서 모두 양수였다.

공식 초과수익을 직접 회귀·분류한 두 신규 모델은 기존 event 모델보다 약했다. 따라서 Agent C의 핵심은 2:1 성공확률과 10세션 하방위험을 함께 보는 기존 구조를 유지한다.

## 결과

| 모델 | 평균 공식지수 초과수익 Rank IC | 양수 초과수익 AUC | 양의 IC 연도 |
|---|---:|---:|---:|
| hist event dual v1 | 0.04184 | 0.51651 | 5/5 |
| hist excess dual | 0.01781 | 0.51747 | 4/5 |
| linear excess dual | -0.00660 | 0.51432 | 3/5 |

선택 모델의 연도별 IC는 2019 `0.01918`, 2020 `0.02592`, 2021 `0.08485`, 2022 `0.03730`, 2023 `0.04197`이다.

## 해석

- 초과수익의 정확한 크기를 직접 맞히는 회귀는 불안정했다.
- 저점 후보의 2:1 성공확률에서 예상 하방위험 순위를 차감하는 구조가 종목의 상대적 향후 초과수익 순서를 더 잘 구분했다.
- AUC는 0.52 안팎으로 낮으므로 이 점수만으로 매수 여부를 확정할 수는 없다.
- 이전 Agent D의 실패를 고려하면 낮은 신호 강도와 turnover를 포트폴리오 단계에서 별도로 통제해야 한다.
