# v2 Phase 4B — Agent D2 이중 결합 구조 실행 보고서

## 결론

`EXP-20260826-007`은 기각됐다. 사용자가 요청한 두 결합 방식 모두 C2 단독 대조군보다는 손실과 위험을 줄였지만, 공식 KRX KOSPI 200 지수 수익률을 넘지 못했다. 진단상 최선은 종목을 제거하지 않고 B2로 C2 순위만 보정한 `B2_RISK_CALIBRATION`이다.

이 결과는 이미 소비된 2019~2023 개발기간 진단이다. 독립 OOS·거래·모의투자 승격 근거가 아니다.

## 실행한 두 구조

1. `B2_TOP80_SERIAL`: Agent B2의 PIT 품질순위 Top 80만 남긴 뒤 Agent C2 기술점수로 매매순위를 정했다.
2. `B2_RISK_CALIBRATION`: C2 전체 종목을 유지하고 `C2 percentile × (0.5 + 0.5 × B2 percentile)`로 순위만 보정했다.

`C2_ONLY_CONTROL`을 같은 체결·비용·청산 규칙의 대조군으로 실행했다.

## Gate

- 연결 순초과수익률 > 0: 실패
- 양의 연도 3/5 이상: 실패(2/5)
- Sharpe > 0: 통과
- MDD > -30%: 통과
- reconciliation PASS: 통과

따라서 최종 결정은 `REJECT_AGENT_D2`다.

## 해석

B2는 C2 신호의 위험을 줄이는 데는 유용했다. C2 단독 대비 위험보정은 순초과수익률을 34.20%p 개선하고 MDD를 16.69%p 줄였다. 그러나 펀더멘털 품질을 hard filter로 쓰면 거래가 더 많아지고 성과가 위험보정보다 나빴다. 따라서 이번 표본에서는 “B2로 먼저 종목을 제한”하는 직렬 구조보다 “C2 후보를 유지하면서 B2로 강도만 조정”하는 구조가 상대적으로 낫다.

다만 두 입력 신호 모두 미래 초과수익 예측력이 약하고, 2019·2020·2023의 강한 지수 구간을 충분히 따라가지 못했다. 현 단계에서 수치 조정이나 결합식 재탐색을 하면 같은 개발기간에 대한 과최적화가 된다.
