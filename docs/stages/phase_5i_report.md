비교용 기존 일별 top-10/20세션 보유 구조도 같은 구간에서 순초과수익률 -12.86%p로 실패했다. 새 지속성·5세션 교체 구조는 이를 개선하지 못했고 turnover를 156.34배에서 212.39배로 높였다.

## 사용 변수와 관계

입력은 Phase 4B에서 고정한 종목 기술변수 21개, 시장상태 5개, 상호작용 6개다. ElasticNet이 매일 종목별 점수를 만들고 EMA5로 평활한 뒤 횡단면 순위를 계산했다. 3세션 연속 상위 10위면 진입 후보, 3세션 연속 20위 밖이면 이탈 후보로 삼았다.

모델 점수는 `reversal_5`와 강한 양의 관계(일별 평균 Spearman 0.877), `trend_close_sma20`과 강한 음의 관계(-0.777), `momentum_20`과 음의 관계(-0.571)를 보였다. 그러나 실제 10거래일 미래 초과수익 순위와의 관계는 각각 0.0215, -0.0146, -0.0074로 약했다. 즉 모델은 단기 반전 중심의 점수를 일관되게 만들었지만 그 점수가 미래 순위를 충분히 예측하지 못했다.

## 결론

학습기간 확대 자체로 횡단면 alpha의 약한 예측력과 높은 회전율 문제가 해결되지 않았다. 이 결과를 본 뒤 같은 2011~2018 구간에서 Feature·모델·threshold·정책을 다시 조정하지 않는다. 이 모델은 거래 후보나 Development Test 공개 후보가 아니다.

## Codex Handoff

Phase 5I는 종료·기각 상태다. 후속 연구는 같은 표본의 추가 튜닝이 아니라 독립 데이터, 다른 사전등록 target 또는 별도 시장 표본을 사용하는 새 Experiment로 설계해야 한다. Development Test와 Final OOS는 계속 봉인한다.
