# v2 Phase 4C — Agent D3 LSTM·CNN 매매 실행 보고서

## 결론

사용자가 제시한 LSTM/CNN 최종점수 0.05·0.075 비중 규칙을 실제 실행했으나 `EXP-20260826-009`는 기각됐다. 최선은 B2 위험보정 후보였지만 전략 -16.28%, 공식 KOSPI200 +38.63%, 순초과 -54.91%p였다.

## 결과

| 후보 | 전략 | 공식 지수 | 순초과 | Sharpe | MDD | 양의 연도 |
|---|---:|---:|---:|---:|---:|---:|
| C3+B2 위험보정 | -16.28% | +38.63% | -54.91%p | -0.135 | -41.57% | 2/5 |
| C3 단독 | -42.19% | +38.63% | -80.82%p | -0.624 | -48.30% | 1/5 |

두 후보 모두 reconciliation은 PASS다.

## 실패 원인

C3 점수에서 0.05 이상은 95.53%, 0.075 이상은 90.90%였다. 다른 모델의 점수척도에서 사용하던 절대 임계값을 C3에 그대로 적용하면서 대부분의 날 상위 후보가 11% 비중으로 진입했다.

최선 후보도 평균 현금 7.10%, 주문 12,285개, turnover 292.06배, 명시적 비용 약 326만원이었다. C3의 순위 예측력 개선이 과도한 반복거래와 상승장 지수 미추종을 상쇄하지 못했다.

이는 LSTM/CNN이 불가능하다는 뜻이 아니다. 모델 점수와 실제 포트폴리오 임계값은 별도로 calibration해야 한다는 뜻이다. 그러나 2019~2023 결과를 본 뒤 이 기간에서 0.05·0.075를 재조정하면 과최적화이므로 수행하지 않았다.
